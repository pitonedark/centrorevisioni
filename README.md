# Tulini Gianni Centro Revisioni

Sito di una pagina. Sede unica: Viale Kennedy 301, 64016 Sant'Egidio alla Vibrata (TE), tel. 0861 842859. Orari: lun–ven 8:30–12:30 e 15:00–18:15, sabato e domenica chiuso.

## Pubblicare su GitHub Pages

1. Crea un repository, meglio se pubblico.
2. Carica `index.html` e `style.css` nella root.
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
4. L’indirizzo sarà `https://tuoutente.github.io/nome-repo/`.

## Foto dell’officina

Crea la cartella `images`, carica le foto e in `index.html` aggiungi, per esempio sotto il titolo:

```html
<img src="images/officina.jpg" alt="Ingresso del centro revisioni">
```
